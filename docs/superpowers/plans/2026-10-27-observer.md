# The observer — implementation plan

> **For agentic workers:** native execution (his choice), superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** A background observer watches the whole cook every 2.5 s, keeps a running log of what was added and done,
answers every turn against that log, and speaks up on its own when it sees a clear mistake.

**Architecture:** Worker: `POST /v1/observe` (one 640 px frame + step + briefing + recent log → `{events, interject}`),
its own per-device daily cap with every 10 observations charged 1¢ to the global cap (migration 0003); turns' prompt
includes the log. Phone: `ObservationLog` and `Observer` (Mac-tested logic) run beside the conversation; a JPEG
downscaler; the runner speaks interjections under the rules; the recorder logs observations.

**Spec:** `docs/superpowers/specs/2026-10-27-observer-design.md`

## Global constraints
- Cadence 2.5 s; one observation in flight; paused while waiting on a timer and after finishing.
- Frames for observation ≤ 640 px long side.
- Interjections: never while the coach is speaking or a turn is in flight, ≥ 20 s apart, one short sentence.
- Observe limit 1,500 per device per Hawaii day; 1¢ to the global row every 10th observation.

## Review focus
1. The observer answers after the step changed — its events still land in the log, stamped; an interjection about
   the old step is dropped.
2. A model answer that isn't JSON, or names an ingredient the recipe doesn't have — no events, no crash, nothing spoken.
3. The cook talks while an interjection is due — the interjection is dropped, not queued.
4. The log grows past 50 lines over a long cook — the newest 50 travel with turns; the full log stays for the recording.
5. The observe cap is reached mid-cook — observing stops quietly; conversation continues.

### Task 3 (iOS, Mac-tested): `ObservationLog` and `Observer`
- Files: `ios/CoachKit/Sources/CoachKit/{ObservationLog,Observer,Downscale}.swift`
- `ObservationLog`: `append(_ events: [String], at: TimeInterval, step: Int)`; `forTurn(limit: 50) -> [String]`
  ("0:51 shook salt over the bowl"); drops exact repeats within 10 s.
- `Observer` away state: 3 consecutive `away` looks → `.away` (one line said: holding the place at step N), cadence
  30 s, no interjections, turns refused locally; a non-away look or "I'm back" → `.present` with a recap built from
  the log and the step. Tests: 2 away looks don't trigger; the 3rd does, once; cadence switches; return recaps once.
- `Observer`: `tick(now:) async` — skips while one is in flight, while waiting/finished; sends the newest frame
  downscaled; appends events; returns an interjection only if allowed (`canInterject(now:, coachTalking:, turnInFlight:)`,
  20 s spacing, same step).
- Tests: log formatting/dedupe/cap; in-flight skip; paused while waiting; interjection rules (talking, in flight,
  spacing, stale step).
- [x] failing tests → implement → pass → commit
