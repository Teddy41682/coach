# Coach

A live AI coach for hands-on tasks. It watches what you're doing through Ray-Ban Meta glasses (or your phone),
talks you through the next step, catches what you missed, and tells you what's wrong — hands-free.
First domain: cooking.

**Built during the Meta Global AI Developer Hackathon, 2026-10-26 → 2026-11-04.** Every commit in this repository
was made inside that window.

Status: under construction.
